# Fun

A Scratch-like desktop application built with ActionScript 3 and Adobe AIR.

## Features

- **80+ blocks** across 8 categories:
  - Motion (10)
  - Looks (12)
  - Sound (8)
  - Events (8)
  - Control (12)
  - Sensing (10)
  - Operators (14)
  - Variables (8)
- **Sprites** with costumes, positions, directions, and sizes
- **Sound manager** with volume and pitch
- **Stage view** with a 480×360 drawing area
- **Block palette** on the left
- **Sprite canvas** on the right

## Requirements

- Apache Flex SDK 4.16+ (or Adobe Flash Builder)
- Adobe AIR SDK (for desktop packaging)
- Java 8+ (for mxmlc)
